# 週末AI MVP v0.1

## 起動
1. ZIPを展開
2. `index.html` をダブルクリック
3. Chrome / Edge で開く

## 今回動くもの
- ホーム
- 条件設定
- 「いつもの条件」の保存・呼び出し
- おすすめ3プラン
- 最近保存したプランと被りにくい簡易ロジック
- プラン詳細
- 保存
- お得額の記録
- 家族プロフィール
- 外出時間から変化する持ち物リスト
- 「今からお出かけ」「AI再プラン」「ナビ」の接続用UI

## 次の段階
実際の位置情報、天気、施設検索、地図/ナビ、営業時間・料金、AI API、音声ドライブモードを順番に接続します。

※ v0.1 の施設・料金・移動時間はUI/操作確認用のサンプルです。


v0.3:
- ブラウザの位置情報から緯度・経度を取得
- Open-Meteoの現在天気（気温・天気コード）を表示
- 位置情報を使わない場合は地名入力から天気取得
- Windows用「起動する.bat」を追加

推奨起動:
「起動する.bat」をダブルクリック → ブラウザで localhost:8000 を利用。
位置情報の許可が出たら許可してください。


v0.4 GitHub Pages版

- v0.2のホームデザインを維持
